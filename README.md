## Шаг 2. Бесплатный хостинг — Render

Бесплатный тариф Render даёт веб-сервис без оплаты. Минус: сервис «засыпает»
после 15 минут простоя и просыпается при первом запросе (примерно 30–60 секунд).
Для бота это нормально: Telegram повторяет доставку обновления.

1. Заведите аккаунт на render.com (можно через GitHub).
2. Загрузите папку `tushenka_bot` в репозиторий GitHub.
3. В Render: **New** → **Web Service** → подключите репозиторий.
4. Настройки:
   - Runtime: **Python**
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
   - Plan: **Free**
5. Вкладка **Environment** → добавьте переменные:
   - `TOKEN` = `9234686778:AAFSBapiM2BYOgGwmvYRKBfdZq6jC0BKdp4`
   - `WEBHOOK_URL` = адрес сервиса, который выдаст Render, например
     `https://tushenka-bot.onrender.com` (без слэша в конце)
6. **Deploy**. После сборки бот сам зарегистрирует webhook.
7. Проверьте: напишите боту в личку «привет».

Альтернативы бесплатного размещения: Koyeb, Fly.io (нужна карта), PythonAnywhere.
Если хостинг не нужен — запускайте локально: `python bot.py` (polling, без WEBHOOK_URL).

## Шаг 3. Добавить бота в канал

1. Откройте канал → **Управление** → **Администраторы** → **Добавить администратора**.
2. Найдите `@Dr_Tushenka_bot`, добавьте.
3. Дайте права: **Публикация сообщений**. Для ответов на комментарии
   включите также **Удаление сообщений** (без этого бот не сможет отвечать в обсуждении).
4. Сохраните.

Важно: в самом канале бот не может «переписываться» — канал предназначен для
публикаций. Чтобы бот отвечал на вопросы, включите у канала **обсуждение**
(привязанную группу): тогда вопросы задаются в комментариях, а бот отвечает там.
5. Проверка: напишите в комментариях под любым постом «привет» — бот ответит.

## Как менять ответы

Откройте `bot.py`, блок `QA`. Ключ — корень слова, поиск идёт по вхождению
в текст в нижнем регистре. Если ничего не найдено — отправляется `GREETING`.
После правок закоммитьте файл — Render пересоберёт сервис автоматически.
